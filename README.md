# ARAMA DICE

A responsive Color Dice + Sign Colors mini-game website.

## Run locally
Open `index.html` in a browser.

## Publish with GitHub + Netlify
1. Create a new public repository on GitHub named `arama-dice`.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
3. Open Netlify and choose **Add new site → Import an existing project**.
4. Connect GitHub and select `arama-dice`.
5. Build command: leave empty. Publish directory: `/` (or `.`).
6. Select **Deploy**. Netlify will give you a public website link.

The uploaded reference images are included in `assets/`.
